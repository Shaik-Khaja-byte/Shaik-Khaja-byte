## 3. Create a token for the stats workflow

The default `GITHUB_TOKEN` in Actions can't read your contribution calendar via GraphQL, so the stats script needs a personal access token:

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens (or classic, with `read:user` scope)
2. Generate one, copy it
3. In this repo: Settings → Secrets and variables → Actions → New repository secret
4. Name it `STATS_TOKEN`, paste the token value

## 4. Run it once manually

Actions tab → **Update Profile Stats** → **Run workflow**. This generates the first real `stats.svg`, `streak.svg`, `langs.svg`, and `contributions.svg` and commits them. After that it runs automatically every day at 03:00 UTC, and also on every push to `main`.

## 5. Push

```bash
git add .
git commit -m "Redesign profile README"
git push
```

That's it — no external API calls happen when someone visits your profile; everything under `assets/svg/` is a file already sitting in the repo.

## 6. Theme support

All SVGs support automatic light/dark theme switching via `prefers-color-scheme` CSS media queries. No duplicated files — each SVG contains both themes and adapts based on the viewer's system preference.
